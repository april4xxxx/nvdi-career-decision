# 登基后新手引导入口｜回退说明

本轮只修改以下三个正式项目文件：

- `js/onboarding.js`
- `css/onboarding.css`
- `index.html`

如需撤回本轮“登基大典结束后必须二选一”的改动：

1. 删除 `js/onboarding.js` 中 `GUIDE_GATE_KEY` 及三个本地状态函数。
2. 在 `renderResult()` 中恢复直接调用 `store.finishOnboarding(..., new Date().toISOString())`。
3. 在 `playTransition()` 中删除 `.cg-guide-choice` 的创建、`revealChoice()` 和两个选择按钮事件。
4. 将过场收尾恢复为：

```js
var timer = setTimeout(enter, 5200);
$("#cgSkip").onclick = function () { clearTimeout(timer); enter(); };
```

5. 删除 `css/onboarding.css` 中 `.cg-guide-choice` 至对应移动端、减少动画规则。
6. 将 `index.html` 的【略过动画】恢复为【跳过】，并恢复原资源版本参数。

此说明只覆盖本轮入口选择改动，不包含项目中其他协作者的修改。
